# **App Name**: Formosan Wordsmith

## Core Features:

- Vocabulary Flashcards: Display interactive flashcards showing Taiwanese Mandarin vocabulary, Pinyin, Japanese translation, and an example sentence from a pre-defined list.
- Audio Pronunciation: Enable users to play audio pronunciation of vocabulary words and example sentences using browser's Text-to-Speech (TTS) on demand.
- Sentence Composition: Provide an input field where users can write their own sentences using the currently displayed vocabulary word for practice.
- AI Grammar Check & Feedback Tool: Integrate with the Gemini API to analyze user-composed sentences for grammatical correctness and naturalness, providing detailed feedback in Japanese.

## Style Guidelines:

- The visual design draws inspiration from the clarity and intellectual pursuit associated with language learning, combined with subtle hints of Taiwan's serene landscapes. We're using a light color scheme to promote focus and readability.
- Primary color: A clear, thoughtful blue (#1486CC). This hue evokes concentration and a professional learning environment, standing out crisply against the light background.
- Background color: A very soft, desaturated sky blue (#EBF5FA). This choice maintains a connection to the primary hue while ensuring maximum readability and visual comfort.
- Accent color: A soft, medium purple-blue (#667ADB). This color, analogous to the primary, provides a distinct but harmonious contrast for interactive elements and highlights, adding a touch of modern sophistication.
- Headlines and key vocabulary terms will use 'Space Grotesk' (sans-serif) for a modern, structured, and distinct feel.
- Body text, example sentences, and AI feedback will use 'Inter' (sans-serif) for its high readability and neutral, professional aesthetic.
- Use a set of clean, minimalist line icons that clearly communicate their function, maintaining the app's overall uncluttered and modern look suitable for a mobile-first experience.
- Adopt a clean, mobile-first design with generous use of whitespace. Content will be presented in a card-based structure for vocabulary display, ensuring a clear hierarchy and easy navigation.
- Incorporate subtle and smooth transition animations for elements such as card swipes, button presses, and feedback display, enhancing user experience without causing distraction.
